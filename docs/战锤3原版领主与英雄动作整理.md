# 战锤3原版领主与英雄 动画与 Variant 整理

> 本文档整理《全面战争：战锤3》原版（含全部已发布 DLC）所有**领主（Lord）与英雄（Hero）**角色对应的 `man_animation` 与 `Variant filename`。

## 字段说明

| 字段 | 说明 |
|------|------|
| **subtype key** | 角色在 `agent_subtypes_tables` 中的主键 |
| **中文名** | 取自原版本地化 `land_units_onscreen_name`（角色基础/步兵形态的显示名） |
| **类型** | 领主 / 英雄（由 `main_units_tables.caste` 判定） |
| **man_animation** | 战斗动作骨架键，来自 `land_units_tables.man_animation`（取**步兵/无坐骑**基础形态，即 `_0` 单位） |
| **Variant filename** | 角色模型变体文件名，来自 `variants_tables.variant_filename`（经 `unit_variants_tables` 关联） |

## 数据关联链

```
agent_subtypes.key
   └─ associated_unit_override ──▶ main_units.unit (caste = lord/hero)
                                    └─ land_unit ──▶ land_units.key
                                                       └─ man_animation        ← [man_animation 字段]
                                    └─ unit_variants.unit ──▶ variant
                                                              └─ variants_tables.variant_filename  ← [Variant filename 字段]
```

> 说明：
> - `man_animation` 会因**坐骑**不同而变化（例如骑马、骑龙、战车等形态各有不同动作）。本表统一取**步兵/无坐骑基础形态（`_0`）**作为代表值。
> - `Variant filename` 对同一角色的所有坐骑形态**保持一致**（角色本体模型不变），故每角色仅列一个。
> - 少数特殊/战役单位（如黑方舟海军领主、商队经略使、序章角色）在 `variants_tables` 中无对应条目，标记为 `—`。
> - 部分传奇领主（LL）的同名王朝/变体领主共享同一 `land_unit`，因此 `man_animation` / `Variant filename` 相同，仅 subtype 与中文名不同。
