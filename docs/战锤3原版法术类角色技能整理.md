# 战锤3原版法术类角色技能整理

> 本文档整理了《全面战争：战锤3》原版（含全部已发布 DLC）所有**法术类角色技能树中的魔法技能**。

> 这些技能常见于各类法师领主与英雄，通常拥有 2~3 个等级，每级提供不同的法术强化效果。

> **亦收录各学派「被动属性」（Lore Attribute）**：如阴之力、阳之强、集焰为炎、萨芙睿之盾等——多为单级技能，解锁对应 `*_lore_passive_*` 战斗被动。速查见 [学派被动属性一览](#学派被动属性一览)。

## 字段说明


| 字段         | 说明                                    |
| ---------- | ------------------------------------- |
| **db key** | 技能在 `character_skills_tables` 中的主键    |
| **中文名**    | 技能的中文译名（取自原版 `localisation__.loc_CN`） |
| **技能效果**   | 各等级（第1级/第2级/第3级）的具体效果，中文描述            |


## 技能效果术语对照


| 术语         | 含义                               |
| ---------- | -------------------------------- |
| 解锁/启用此法术   | 该技能学习后，法师可在战斗中施放此法术（或解锁该法术的强化版）  |
| 解锁超载施法     | 解锁该法术的超载（Overcast）版本，威力更强但消耗更多魔风 |
| 冷却时间 ±X%   | 该法术的冷却时间修正（负值为减少/更快）             |
| 魔法消耗 ±X    | 该法术基础版魔风消耗修正                     |
| 超载版魔法消耗 ±X | 该法术超载版魔风消耗修正                     |
| 施法失误率降低 X% | 降低该法术施法失误概率（失误会自伤）               |
| 强化XX(学派被动) | 增强该魔法学派的固有被动效果                   |
| 解锁/启用此法术（学派被动） | 解锁该学派 Lore Attribute 战斗被动（`*_lore_passive_*`） |




## 技能变体说明

同一法术的技能通常存在多个变体，本文档完整列出：

- **基础版**（无后缀）：英雄法师使用，通常 3 级
- `_lord` **版**：领主法师使用，通常 2 级（起始即解锁超载）
- **传奇角色专属版**（如 `_teclis`、`_kairos`、`_kihar`、`_branchwraith`、`_slann` 等）：传奇法师的定制版本
- `_warlock` **版**：斯卡文工程术士使用
