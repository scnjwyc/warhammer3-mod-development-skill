# 已验证案例经验

本文件保存妲己和 A2 的经验作为诊断范例。所有顶点编号、骨索引、SHA、动作键、阈值、比例、LOD 数和候选参数都仅属于各自资产；未来任务必须从当前活动资产和真实动作重新取证。

## 妲己：静态权重正常，不代表手指链正确

### 现象与证据

- 活动资产链为 `daji.variantmeshdefinition -> model/daji/daji2.wsmodel -> model/daji/daji2.rigid_model_v2`。
- 活动 RMV2 使用 `humanoid01e`。正确标准 bind pose 必须来自该 skeleton 的 `.anim`；一个骨骼表名匹配但不是标准 bind pose 的参考姿势，手骨可能相差数十厘米，不可用于权重结论。
- 静态检查中没有跨手指影响、无权重顶点或超过四 influence，但真实 `hu1e` 法师动画仍揭示右食指扭曲。
- 根因不是“所有缺失 `_0` 顶点组都应补齐”，而是局部从指根 `_0` 直接跨到末节 `_2`，中间节 `_1` 在攻击/施法中单独旋转，形成断链折叠。

### 可迁移原则

1. 手指问题必须按真实攻击、施法、待机等动作验证，而不是只看权重表或 reference pose。
2. 骨链中段发生独立转动时，顶点 influence 必须在链上连续过渡。
3. 修复可在一个空 slot 中加入中间骨并按整数权重重新分配，但前提是当前模型格式、slot 状态、骨骼索引映射和真实动作均已证明该操作。
4. 记录局部自交、攻击峰值和近景渲染，对比修复前后，而不是只报告“写入成功”。

妲己最终 V3 的旧实验目录未随包提供；它的特定 80/20 分配、骨索引和 SHA 不可直接迁移。

## A2：跨骨架家族时，权重平滑不能替代 bind 位置重定向

### 现象与证据

- 活动链为 `a2.variantmeshdefinition -> model/a2/a22.wsmodel -> model/a2/a22.rigid_model_v2`，当前活动骨架是 `humanoid01`。
- `a22` body 与旧 `male01` 参考模型同拓扑；旧 `humanoid01d` A2 文件只是历史参考，不是运行时模型。
- 用户认可的 V3 已修复手腕、髋、膝等局部权重问题，但后腰中央在真实 Ulrika 动作中仍扭曲。
- 从旧 `male01` 和新 `humanoid01` 标准 skeleton 的 world bind matrices 推导显示：`root/upperleg` 差距接近 1 mm，而 `spine_0/spine_1` 的 bind transform 大约需要 10 cm 级移动。红框核心顶点也出现数十毫米的理论位置误差。
- 多轮 root/leg/spine 权重平滑只能转移折角，不能消除根因；用空间盒硬阈值直接移动顶点会在选区边界打开腰线。

### 最终方法的通用部分

1. 先用 Blender evaluated mesh 验证线性蒙皮矩阵口径。
2. 在旧/新 skeleton 名称映射和同拓扑成立时，用 `new_world @ inverse(old_world)` 与原始 LBS 权重求理论 rest position。
3. 核心高误差点直接对齐理论位置。
4. 以三角面拓扑为邻接，向外做 smoothstep 衰减。将同坐标 seam 副本折叠成同一逻辑节点后求距离，避免副本多走一圈。
5. 同步同位置副本目标位置，并保留另行证明的 seam 权重修复。
6. 用相同攻击、受击、跳劈等帧比较二面角、seam separation、边/面积畸变、重叠和全子网格画面。

### 明确不迁移的参数

- A2 body mesh 名、后腰空间盒、误差阈值、核心顶点数、8 圈衰减、顶点/封缝编号、`male01`/`humanoid01` 组合。
- `spine_1 -> spine_0` 权重转移比例。
- 任何已否决的 V4、硬空间阈值、低位混合或旧 topology candidate SHA。
- Ulrika 的动作键和具体帧号。

A2 的旧实验资产和完整报告未随包提供；本文只保留当时的方法结论，不宣称当前可复现，不构成未来角色的默认修复参数。

## 候选淘汰经验

| 现象 | 含义 | 后续方向 |
|---|---|---|
| 同坐标 seam 在动作中分离 | duplicate 副本权重或目标位置不同 | 建立 logical cluster，同步写入并测 separation。 |
| 指标改善但渲染出现开口 | 选区边界或过渡不连续 | 扩展真实网格邻接环，不能直接扩大空间盒。 |
| 理论 bind 误差趋近零但全域 overlap 增长 | 修复范围过大或指标覆盖正常身体关系 | 收缩到局部拓扑区域，比较全子网格画面。 |
| 局部最坏值不变 | 最大值来自未改区域 | 按核心区域、top N% 和具体 edge/triangle 重新汇总。 |
| body-only 有洞、全子网格无洞 | 原模型衣物覆盖切口 | 保留 body-only 诊断，但以 full-model 渲染判断可见回归。 |
| 参考模型表面最近但动作更差 | 体型或 bind family 不兼容 | 不要把最近面权重直接转移；回到当前模型拓扑或 true bind 计算。 |

目标不是让某一单项数值最小，而是用最小、可审计的变更同时满足真实动作、二进制约束和可见画面。
